  `pricing_history` with `valid_from`/`valid_to`, `pricing_snapshots`) created with
  `CREATE ... IF NOT EXISTS`; `init_db(path)` + `connect(path)` (enforces
  `PRAGMA foreign_keys`).

  transaction, exactly one snapshot row per run. Idempotent.
- **`tests/`** — 13 tests (clean-seed counts, run-twice idempotency, FK resolution,
  unknown-reference rejection, one snapshot row per run, root disclaimer contract).

  verified stable across two runs — 4 / 5 / 19 / 1 rows. Not committed.
- **`probe_config.yaml`** test command narrowed to `.venv/bin/python -m pytest tests/ -q`;
  **CI** now provisions a root `.venv` so the same command runs locally and in CI.
