# portfolio-showcase

> **Work in progress.** Scaffolding only — see `PLANBOOK.md` for build status.

A seeded competitor-pricing pipeline: scraped data → SQLite → FastAPI + HTMX dashboard,
with a Jupyter walkthrough for the analysis narrative.

**All pricing data in this repository is illustrative and was not collected from live
vendor sites.** Data is fixed at `data_as_of: 2026-10-01`. Vendor names are used to
describe a realistic scenario only; this project is not affiliated with, endorsed by,
or acting on behalf of any vendor mentioned.

Full documentation lands in Phase E (`README.md`, `LOCAL_SETUP.md`, `TECH_STACK.md`,
`01_PRICING_SCRAPER_CASE_STUDY.md`).
